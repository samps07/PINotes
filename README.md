# 📌 PINotes

PINotes is a modern Android notes app focused on making it easy to **capture, organize, and revisit information**.

It supports everything from simple notes and checklists to tables, attachments, reminders, notifications, and AI-assisted organization.

## ✨ Features

### 📝 Notes

- Create, edit, and delete notes
- Text formatting
- Create lists and checklists
- Easily create table-style notes
- Attach images and files
- Pin important notes
- Organize notes with categories
- Add manual tags
- Automatically generate tags using AI

### 🔔 Notifications

- Push notes directly to your notification
- Schedule notes to appear as notifications
- Edit notes directly from the notification
- Preview attached images in notifications
- Open links directly in their appropriate apps

### 📤 Quick Capture

Share content to PINotes directly from **any Android app** without manually opening PINotes.

Supports sharing:

- Text
- Links
- Images
- Other media/files

Example:

`Browser → Share → PINotes → Save`

### 🤖 AI Curation

AI can help organize information inside your notes by:

- Curating links
- Processing text
- Automatically generating relevant tags

### 🔗 Sharing

- Generate shareable links for notes
- Share notes without manually copying their contents

### 🎨 Modern UI

- Material You-inspired design
- Clean and modern interface
- Simple navigation
- Designed for both quick notes and structured information

### ☁️ Offline & Sync

PINotes can be used offline, with cloud synchronization available when needed.

Sync uses **Firebase Authentication** so each user's synced data is associated with their own account.

---

## 🔐 Privacy

PINotes supports local/offline usage, so an internet connection isn't required for basic note-taking.

For users who enable synchronization, Firebase Authentication is used to keep user data separated between accounts.
